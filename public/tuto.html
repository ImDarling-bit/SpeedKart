1Ce qu'il faut

L'hôte (une seule personne)

Un PC Windows avec internet et une carte graphique correcte. C'est lui qui fait tourner la partie (bots, objets, ballon) : il garde le jeu ouvert jusqu'à la fin.

Les amis

Un PC (ou une tablette / un téléphone récent) avec un navigateur à jour (Chrome, Edge, Firefox) et internet. Rien à installer.

De 1 à 8 pilotes, hôte compris. Les places libres sont complétées par des bots. Une manette (Xbox, PlayStation) est conseillée mais pas obligatoire.

2Installer le lanceur

Uniquement pour l'hôte, et une seule fois : le lanceur se met ensuite à jour tout seul.

  1. Télécharge l'installeur SpeedKart-Setup (fichier .exe, environ 110 Mo) :

    Télécharger le lanceur

  2. Ouvre le fichier téléchargé. Windows peut afficher « Windows a protégé votre ordinateur » : le lanceur n'est pas signé par un éditeur payant, c'est normal.

    Windows a protégé votre ordinateur Informations complémentaires Exécuter quand même

    Clique sur Informations complémentaires, puis sur Exécuter quand même.

  3. L'installation est automatique (pas besoin de droits administrateur) et le jeu s'ouvre tout seul. Un raccourci SpeedKart est ajouté au bureau et au menu Démarrer.

  4. Si Windows demande d'autoriser le programme sur le réseau, accepte au moins pour les réseaux privés. Refuser ne bloque pas les parties en ligne.

  5. Astuce : F11 passe le lanceur en plein écran.

Pas de PC Windows ? L'hôte peut aussi jouer depuis la page du jeu dans Chrome ou Edge sur ordinateur (Mac et Linux compris). Il vaut mieux garder l'onglet du jeu affiché pendant toute la partie.

3Créer la partie et inviter

  1. Dans le lanceur, tape ton pseudo puis clique sur Créer une partie. (Pour t'entraîner seul contre les bots, sans internet : Jouer en solo.)

    Ton pseudo Pilote Fou Créer une partieJouer en solo

  2. Un code à 4 lettres apparaît en haut du salon. Clique sur Partager pour envoyer le lien à tes amis (Discord, WhatsApp, SMS...), ou dicte-leur simplement le code.

    Code KTLG https://imdarling-bit.github.io/SpeedKart/?code=KTLGPartager

  3. Quand tes amis apparaissent dans la liste Pilotes, choisis le mode, les réglages, puis lance la partie avec le gros bouton jaune.

Important L'hôte garde le jeu ouvert jusqu'à la fin. S'il le ferme, la partie s'arrête pour tout le monde.

4Rejoindre (les amis)

  1. Ouvre le lien reçu. Le code est déjà rempli.

  2. Tape ton pseudo et clique sur Rejoindre. Sans lien, ouvre la page du jeu et tape le code donné par l'hôte.

    Ton pseudo Bob KTLGRejoindre

  3. Choisis ton véhicule, ta couleur et ton klaxon pendant que l'hôte prépare la partie.

5Le salon en 4 étapes

Les étapes sont en haut de l'écran ; on passe de l'une à l'autre avec Suivant et Retour, ou en cliquant dessus.

1 · Mode (l'hôte)

Course, Police / Voleurs (avec sa règle : braquage, chasse, contamination, évasion), Foot turbo, Tamponneuses ou Bataille de ballons.

2 · Véhicule (tout le monde)

29 véhicules par catégorie, avec un grand aperçu 3D. Les barres indiquent la vitesse, l'accélération, la maniabilité et le poids : un poids lourd pousse les autres, un kart léger tourne et accélère mieux. Choisis aussi ta couleur, ton klaxon et, au foot, ton équipe.

3 · Carte et réglages (l'hôte)

Le circuit ou la ville, puis les réglages : tours, cylindrée, durée, taille des équipes, ballons, bots, objets, pouvoirs aléatoires, physique tamponneuse.

4 · Salle d'attente

Les pilotes présents, le résumé de la partie et le championnat (les points s'additionnent d'une partie à l'autre). L'hôte appuie sur Lancer.

Paramètres Le bouton (ou Paramètres sur l'écran titre) règle la qualité graphique, la taille de l'interface, le son, la caméra et permet de changer les touches. En partie, Échap ouvre le menu pause.

7Les modes de jeu

Course

14 circuits, dont 9 avec des loopings : prends le tapis orange juste avant pour avoir assez d'élan, sinon tu retombes. Ramasse les boîtes ? pour des objets (turbo, bananes, carapaces, bombe, étoile, bouclier, éclair). Dérape longtemps pour un mini-turbo bleu, orange puis violet.

  • Pouvoirs aléatoires : chacun reçoit un pouvoir (géant, échange de place, téléportation, gel, encre, comète...), utilisable avec R quand il est rechargé. Un nouveau est tiré à chaque fois, sans répétition rapprochée.
  • Physique tamponneuse : chocs violents qui font faire des tonneaux, et une gravité qui ondule.

Police contre voleurs

Dans une ville (Centre-Ville, Zone Industrielle ou Le Port). Environ un tiers des joueurs sont policiers, en voiture de police imposée ; les voleurs gardent leur véhicule. Les rôles tournent à chaque manche, et les voleurs ont 5 s d'avance au départ. La police arrête un voleur en le percutant, et ne le voit sur sa carte que de près, ou quand elle allume la sirène.

  • Braquage : les voleurs ramassent les sacs d'argent (3 au maximum, ça ralentit) et les rapportent à la planque. Arrêtés, ils vont en prison ; un complice libre roule sur le bouton rouge pour les libérer.
  • Chasse à l'homme : la police doit arrêter tout le monde avant la fin du temps.
  • Contamination : un voleur arrêté devient policier. Le dernier voleur libre gagne.
  • Évasion : les sorties s'ouvrent au bout de 20 s ; les voleurs doivent les atteindre.

Gadgets (touches E R F) : la police a la sirène, la herse et un barrage de cônes ; les voleurs ont la nitro, le fumigène et l'huile.

Auto-tamponneuses

Une plateforme flottante, sans barrières. +1 point pour chaque adversaire retourné, +2 pour chaque éjection dans le vide. Toutes les 14 s, la gravité change : lunaire, écrasante, penchée, folle... Les plots roses te renvoient très fort, et attention à la barre qui tourne au centre.

Foot turbo

Façon Rocket League : Bleus contre Orange avec un ballon géant. Saute, refais un saut en tenant une direction pour une figure qui frappe fort, utilise le turbo (recharge sur les pastilles orange) et roule sur les murs et le plafond. En cas d'égalité, prolongation avec but en or.

Bataille de ballons

Chacun a des ballons (3 par défaut). Touche les autres avec tes objets pour crever les leurs ; à zéro, tu es éliminé. Le dernier debout gagne (ou celui qui a le plus de ballons à la fin du temps).

8En cas de souci

« Partie introuvable »

Vérifie le code (4 lettres, ni I ni O). L'hôte doit avoir le jeu ouvert avec la partie créée. Si l'hôte a fermé puis rouvert le jeu, c'est une nouvelle partie avec un nouveau code.

« Connexion perdue »

Le jeu se reconnecte tout seul pendant 30 secondes. Si ça ne revient pas, rejoins à nouveau avec le même code.

Impossible de se connecter en 4G ou au travail

Certains réseaux mobiles ou d'entreprise bloquent les connexions directes entre appareils. Passe sur un Wi-Fi de maison et réessaie.

Le jeu saccade

Ferme les autres onglets et applications lourdes, branche le PC portable sur secteur, et vérifie que le navigateur utilise la carte graphique (Chrome : chrome://gpu). Sur un vieux PC, préfère les modes en arène, plus légers que les circuits.

Le son du moteur est trop fort

Dans Paramètres → Son : un curseur pour le volume général, un autre uniquement pour le moteur. Les réglages sont gardés pour les prochaines parties.

Ma manette ne répond pas

Branche-la avant d'ouvrir le jeu, puis appuie sur un bouton une fois la page ouverte : le navigateur ne la détecte qu'après un premier appui.

Mettre à jour le lanceur

Rien à faire : le lanceur télécharge les nouvelles versions tout seul et les installe quand tu le fermes, jamais en pleine partie.

9Installer depuis le code (avancé)

Pour modifier le jeu ou l'héberger soi-même. Inutile pour jouer.

  1. Installe Node.js (version 18 ou plus récente) et Git.

  2. Récupère le code et ses dépendances :

    git clone https://github.com/ImDarling-bit/SpeedKart.git
cd SpeedKart
npm install

  3. Lance le jeu :

    npm start          # la page sur http://localhost:3000
npm run desktop    # ou le lanceur Electron

    Les amis du même Wi-Fi peuvent ouvrir l'adresse affichée dans le terminal (http://192.168.x.x:3000).

  4. Après une modification, vérifie que tout tient :

    npm run simulate   # circuits, loopings, bots et modes en arène, sans navigateur
Aller jouer
